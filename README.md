# Gardhub Insights

A responsive Somali-language publication with a React/Vite frontend, Express REST API, and MongoDB storage.

## Requirements

- Node.js 20 or newer
- MongoDB running locally, or a MongoDB connection string

## Run locally

1. Copy `.env.example` to `.env` and set `ADMIN_KEY` to a long, private value. The default MongoDB URI is `mongodb://127.0.0.1:27017/gardhub_insights`.
2. Install dependencies from the project root with `npm install`.
3. Start the frontend and API together with `npm run dev`.
4. Open `http://localhost:5174`. The Vite development server proxies `/api` requests to `http://localhost:5000`.
5. To insert the sample stories, including the two Amni security reports, run `npm run seed`. Seeding is repeatable and adds missing stories even when the database already contains articles.

The production frontend build is `npm run build`; `npm start` starts the Express server, which serves the built frontend when available.

## REST API

The public website is read-only. The unlinked owner dashboard is available at `/admin` and requires the `ADMIN_KEY` secret to unlock. The key is held only in the current page session. API-created posts are attributed to Gardhub - Tifatire.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/api/health` | API and database health |
| POST | `/api/admin/verify` | Verify the owner key; send `x-admin-key` |
| GET | `/api/articles?category=Amni&search=...` | List articles; `category` and `search` are optional |
| GET | `/api/articles/:idOrSlug` | Fetch one article by MongoDB ID or slug |
| POST | `/api/articles` | Publish an article; send `x-admin-key` |
| DELETE | `/api/articles` | Delete all articles; send `x-admin-key` |
| DELETE | `/api/articles/:idOrSlug` | Delete an article; send `x-admin-key` |

POST JSON body:

```json
{
  "title": "Cinwaan maqaal",
  "content": "Qoraalka maqaalka...",
  "excerpt": "Soo koobid kooban.",
  "category": "Teknolojiyad",
  "readTime": 5,
  "coverImage": "https://example.com/image.jpg"
}
```

Supported categories are `Teknolojiyad`, `Siyaasad`, `Amni`, `Caafimaad`, and `Dhaqaale`. `readTime` is optional for API callers and must be an integer from 1 to 180; it is calculated from content when omitted. `coverImage` is optional and must be an HTTPS URL. `slug` and `createdAt` are generated by the API. Write and delete routes are disabled until `ADMIN_KEY` is configured; API-created articles are always attributed to Gardhub - Tifatire. The public website is read-only, with publishing reserved for the owner through the protected dashboard, API, or database seed workflow.

## Deploy to Vercel

For the full-stack deployment, import this repository in Vercel and keep the project Root Directory at the repository root (`.`). The root `vercel.json` installs root and client dependencies, runs `npm run build`, publishes `client/dist`, and routes `/api` requests through the Express serverless function. Configure `MONGO_URI`, `ADMIN_KEY`, and `CLIENT_ORIGIN` in the project environment variables, and use a hosted MongoDB deployment for production.

For a frontend-only deployment, Vercel may use `client` as the Root Directory; use `npm install`, `npm run build`, and `dist` as the output directory. In that setup, the root `/api` serverless function is outside the deployment and must be hosted separately for article and admin API features to work.

This repository is already connected to GitHub. Commit and push changes from the existing repository; never commit `.env` or its secrets.
